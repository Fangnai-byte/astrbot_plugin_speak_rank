# Speak Rank (群发言榜)

![logo](logo.png)

一个 [AstrBot](https://github.com/Soulter/AstrBot) 插件：统计群内发言条数，群友在群里发关键词即可查看本群发言排行。

## 功能

- **多种口径**：今日 / 昨日 / 前天 / **指定日期** / 本周（周一起）/ 累计，关键词即可查询
- **按群独立统计**：各群互不干扰
- **机器人也算**：机器人自己的发言默认计入榜单（`include_bot=true`，自己发言不需要排除）；机器人消息永远不会自己触发查询，不会自我循环
- **sqlite 落盘**：重启不丢数据，增量累计
- **昵称兜底**：群成员无群名片时，协议端会把昵称上报成纯数字 QQ 占位（榜单会显示「未备注」）；此时自动回填该用户的历史有效昵称，实在没有才显示 QQ 号
- **上榜不记仇**：昵称过滤纯数字/空串/占位串（bot、null、n/a 等），只取最近一次发言时的有效名

## 用法

在群里发送：

| 关键词 | 结果 |
| --- | --- |
| 发言榜 | 今日发言 TOP10（默认） |
| 今日发言榜 | 今日 TOP10 |
| 昨日发言榜 / 昨天发言榜 | 昨日 TOP10 |
| 前日发言榜 / 前天发言榜 | 前天 TOP10 |
| 9月7日发言榜 | 9月7日当天 TOP10（默认今年） |
| 2026年9月7日发言榜 | 指定年某日 TOP10 |
| 2026-09-07 发言榜 | 同上，支持 `-` `/` `.` 分隔 |
| 本周发言榜 | 本周（周一起）TOP10 |
| 累计发言榜 / 总发言榜 | 累计 TOP10 |

> 提示：指定日期可以是未来或很久以前，没有数据的日期会返回「暂无数据」。

触发关键词与榜单条数可在插件配置里调整（`trigger_words` / `top_n`）。

## 安装

将本插件目录放入 AstrBot 的 `data/plugins/` 下，在 WebUI 插件管理中启用即可。

## 数据

SQLite 数据库保存在插件目录 `data/speak_rank.db`，删除即清空历史。榜单按**自然日**（本地时区）聚合，启用插件当日起开始累计，更早的日期无数据。

## 配置

- `top_n`：榜单条数，默认 10
- `trigger_words`：触发关键词列表，留空用内置兜底（发言榜、水群榜）
- `include_bot`：机器人自身发言是否计入，默认 true
- `bot_display_name`：机器人上榜时的显示名，默认「绫地宁宁」（框架把机器人昵称记作 `bot` 或纯数字 QQ 占位，展示时按 self_id 统一替换）
- `exclude_user_ids`：不参与计数的 QQ 号
