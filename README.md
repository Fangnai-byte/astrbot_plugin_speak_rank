# Speak Rank (群发言榜)

![logo](logo.png)

一个 [AstrBot](https://github.com/Soulter/AstrBot) 插件：统计群内发言条数，群友在群里发关键词即可查看本群发言排行。

## 功能

- **三种口径**：今日 / 本周（周一起）/ 累计，关键词即可查询
- **按群独立统计**：各群互不干扰
- **机器人也算**：机器人自己的发言默认计入榜单（`include_bot=true`，自己发言不需要排除）；机器人消息永远不会自己触发查询，不会自我循环
- **sqlite 落盘**：重启不丢数据，增量累计

## 用法

在群里发送：

| 关键词 | 结果 |
| --- | --- |
| 发言榜 | 今日发言 TOP10（默认） |
| 今日发言榜 | 今日 TOP10 |
| 本周发言榜 | 本周 TOP10 |
| 累计发言榜 / 总发言榜 | 累计 TOP10 |

触发关键词与榜单条数可在插件配置里调整（`trigger_words` / `top_n`）。

## 安装

将本插件目录放入 AstrBot 的 `data/plugins/` 下，在 WebUI 插件管理中启用即可。

## 数据

SQLite 数据库保存在插件目录 `data/speak_rank.db`，删除即清空历史。

## 配置

- `top_n`：榜单条数，默认 10
- `trigger_words`：触发关键词列表，留空用内置兜底（发言榜、水群榜）
- `include_bot`：机器人自身发言是否计入，默认 true
- `bot_display_name`：机器人上榜时的显示名，默认「绫地宁宁」（框架把机器人昵称记作 `bot`，展示时统一替换）
- `exclude_user_ids`：不参与计数的 QQ 号
